# Reverse

Open-source, local-first social graphics editor. Create Instagram posts, stories, YouTube thumbnails, and X posts in the browser — then export PNG/JPG.

Built clean-room from common design-editor UX patterns. No proprietary code or reverse engineering of commercial products.

## Features (MVP)

- Presets: Instagram post / story, YouTube thumbnail, X post
- Text, rectangles, circles, image upload, solid backgrounds
- Original JSON templates
- Layers, undo/redo, zoom
- PNG/JPG export at 1× and 2×
- Designs saved in IndexedDB (no account)

## Quick start

```bash
npm install
npm run dev
```

## Stack

Vite · React · TypeScript · Fabric.js · Zustand
